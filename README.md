# Documentación Administradores HPC Facultad de Ingeniería UNAL

Repositorio de documentación dirigido a administradores del clúster HPC.

## Contenido

- Documentación en `docs/`
- Guía general de MkDocs en `Guia_general_MkDocs.md`

## Vista previa local

```bash
mkdocs serve -f mkdocs.yml
```

## Compilación

```bash
mkdocs build -f mkdocs.yml
```
